# 🎓 Student Performance Prediction ML Project

A complete Machine Learning and Web Application project built in Python using Scikit-learn and Streamlit to predict whether a student will pass or fail based on lifestyle and academic features.

---

## 📁 Project Structure

```text
Student Performance Prediction ML project/
│
├── .venv/                   # Python virtual environment
├── student_data.csv         # Dataset containing student attributes
├── requirements.txt         # Required Python packages
├── train_model.py           # Script to train and save the ML model
├── student_model.pkl        # Saved Random Forest model
├── app.py                   # Streamlit web application interface
└── README.md                # Project documentation
